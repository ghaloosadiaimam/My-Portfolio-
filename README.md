# Sadia Imam - IT Portfolio

Responsive portfolio built with HTML, CSS and JavaScript. All files are in one folder.

- index.html, style.css, script.js: the website
- cv.pdf: CV (opens in a new tab)
- *-thumb.jpg: certificate previews; pdf/jpg files: full certificates

Deploy: upload all files to GitHub, import the repository in Vercel, Framework Preset: Other.
